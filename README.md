# Installation
```
conda env create -f imolcry_M3Mac.yml # this script can be used in linux
pip install -e .
```
Additionally, you can optimize force field parameters by using [DMFF](https://github.com/deepmodeling/DMFF).  
The sample codes for the optimization are located in [the example/opt](https://github.com/srak-uf/imolcryff/tree/main/examples/opt) directory.
